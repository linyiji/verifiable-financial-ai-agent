# 产品概览

[English](PRODUCT_OVERVIEW.md)

Verifiable Financial Agent（向风行 AI）将研究目标转化为协同财务研究，并提供可检查的结果和持久化记忆。

**Make It Useful（让它有用）：** 确认由模型生成的 Scheme，再由 Research Lead 与专业 Agent 执行依赖感知的任务图、纠正局部问题，并在有充分理由时重新规划。

**Make It Trustworthy（让它可信）：** 受支持的主张与证据、确定性计算、财务检查、有界证明以及可观测执行身份绑定。恢复决策拥有独立的策略和尝试证据。部分映射仍明确显示为部分覆盖。

**Make It Better With Use（让它越用越好）：** 已发布研究成为类型化记忆。增量研究更新时效性数据、重新验证结论并防止已知错误；下一份已发布视图会与其知识基线进行比较。这是已经实现的复用机制，不是在线模型训练。

面向受邀研究人员、分析师和技术评估者。状态：Local Deployable Alpha / Controlled Alpha Ready。它不代表投资建议、公开 SaaS 或企业级就绪。
