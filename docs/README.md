## Bilingual documentation policy

English documents use `FILE.md`; Simplified Chinese mirrors use `FILE.zh-CN.md`.
Each pair provides a reciprocal switch below its title. Chinese documents prefer
Chinese document links; code, images and machine evidence remain shared.
Commands, flags, route/model IDs, SHAs and authoritative status tokens are not translated.
Historical receipts retain historical failures and limitations, not current capability claims.

Unlinked historical engineering files in `docs/archive/engineering/` are exempt from
full translation. They are not current evaluator instructions; archive manifests and
checksums describe the original package. A newly linked archive document requires a
Chinese mirror before it becomes part of the current product reading path.
