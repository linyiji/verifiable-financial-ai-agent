# Phase 6A Closure-8 reliability contract

[中文](PHASE6A_CLOSURE8_RELIABILITY.zh-CN.md)

The REQUIRED material-risk follow-up remains independent of the successful main Risk output.
Missing required output still blocks Review, Proof, Report and Release. Historical failed runs
and published tags are immutable.

For `risk_follow_up`, prospective authorized routes retain Sol → Luna → Terra → MiMo order.
Registry authority and model execution policy remain mandatory. A provider response cannot
authorize a model. Unknown routes require a governed exact-input capability check; successful
validated check output is consumed once. Checks count as actual attempts, with four requests,
two same-provider model transitions, one cross-provider transition and three checks maximum.
The overall task deadline remains 300 seconds; other task defaults and transport limits do not
increase. Provider deadline failures are recoverable only within remaining task authority and
budget. Task deadline expiry stops without another request. Transport failure alone does not
establish that a model lacks semantic capability.

The typed follow-up context includes the exact parent output and artifact hash, the material
question, selected accepted evidence facts, successful calculation values/formulas and durable
references. It excludes unrelated narratives and recovery history. The parent has no claim-level
references, so none are invented. Calculation input lineage remains in canonical records and
complete AgentOutput input references; repeated identifier lists are not copied into the prompt.
References without supplied facts are not additional knowledge, and unresolved gaps must be disclosed.
