# 评估者凭据安全基础

[English](EVALUATOR_CREDENTIAL_SECURITY.md)

在网关评估模式中，供应商密钥仅留在服务器端。评估者设备接收的是不透明、限定权限范围、会到期、可撤销且有配额限制的 bearer 凭据，而不是上游密钥的加密副本。本地设备所有者／管理员可以提取进程中的秘密：**本项目不声称本地秘密无法提取**。网关策略才是权限边界。

当前评估指引（2026-09-08）：Owner 网关处于 NOT_DEPLOYED，因此建议投资者和测试员使用直接调用 API 的 BYOK 方式进行有人协助的测试。BYOK 使用用户自己的 Key，或由 Owner 私下单独提供、具有独立权限范围的测试 Key，并在本地配置。内置 API 调用能力不等于在源码、镜像或安装器中内置密钥。一键安装器仍是仅面向网关的基础版，不是一键 BYOK 安装路径；请参阅[高级安装](../deployment/ADVANCED_INSTALLATION.zh-CN.md)。

## 组件与权限

本地产品 → EvaluatorGatewayLLM / EvaluatorGatewayFinancialData → Owner 网关 → 现有 MiMo / TeamoRouter / FMP 权限。显式设置 `VFA_CREDENTIAL_MODE=evaluator` 后，必须具有已激活的进程内会话。缺少网关／会话权限时按失败关闭原则处理；系统绝不会因为缺少密钥就切换到 BYOK。为兼容旧配置，默认模式为 BYOK。投资者／测试员应根据当前直接 API 指引显式配置 BYOK，而不是依赖默认值或网关自动回退。

网关签发的 bearer 秘密为 32 个随机字节（URL 安全编码，带 `vfa_` 前缀）。私有 SQLite 存储仅保留 SHA-256 校验值、公开 ID 以及策略／计量状态。校验值抵抗猜测依靠的是令牌的高熵，而不是人类密码。每次分发前，以事务方式检查到期、撤销、权限范围、配额和速率；readiness 也会重新检查到期／撤销状态。令牌不会赋予管理权限、任意模型选择、主机／路径选择或读取供应商秘密的能力。被盗令牌在到期／撤销之前，可能消耗其剩余授权额度。

## 可移植加密凭据包

版本 1 使用 AES-256-GCM、随机 96 位 nonce 和 128 位认证标签，采用 Scrypt（`N=32768, r=8, p=1`）结合随机 128 位盐派生 32 字节密钥。网关 URL、版本和凭据 ID 属于经过认证的关联数据。修改元数据或密文会触发失败关闭。解析器拒绝重复／未知字段、过大／损坏的封装以及不支持的版本；不可信凭据包不能提高固定的 KDF 参数。密码必须为 12–1024 个字符；请使用随机、高熵的激活秘密，而不是易猜短语。加密文件被盗后，仍有可能遭到离线密码猜测。

这些是成熟密码学库提供的原语，而非自创密码学：[cryptography AESGCM 文档](https://cryptography.io/en/latest/hazmat/primitives/aead/)和 [Scrypt 文档](https://cryptography.io/en/latest/hazmat/primitives/key-derivation-functions/)。AEAD 使用密码派生密钥认证凭据包元数据；它不是 Owner 数字签名。请通过可信的 Owner 渠道获取凭据包，并分别获取秘密。HTTPS 及可选配置的 origin 固定约束可保护预期的网关路由。评估者到网关的传输和网关的模型传输禁用重定向与环境 HTTP 代理。现有 Owner FMP 传输保留环境代理行为；Owner 必须确保该环境安全。显式回环 HTTP 仅限开发使用。

## 本地凭据生命周期

启动器使用终端隐藏输入提示密码；如果无法安全提示，则直接失败。它在内存中解密、调用 readiness，并且只有凭据 ID 匹配后才激活会话。不支持令牌参数、环境变量、明文 dotenv、本地令牌缓存或 UI 字段。原生启动器在同一进程中启动后端。Docker 安装器则通过子进程标准输入与私有 tmpfs Unix socket 传递令牌；API 在激活进程内会话前会再次检查 readiness。两种路径均不持久化令牌缓存。退出会清除会话引用；Python 无法保证立即将内存清零。崩溃转储、交换空间、调试器访问、恶意依赖、终端捕获和已被攻陷的主机，均不在这一基础方案的保护范围内。请相应保护主机以及凭据包／密码的分发过程。

macOS Keychain：**NOT_IMPLEMENTED**。Windows Credential Manager：**NOT_IMPLEMENTED**。两个平台与 WSL2 均使用可移植的仅会话路径。带空格／Unicode 的 POSIX 路径和 Windows 驱动器路径语法已有离线覆盖；本任务未验证原生 Windows/WSL2 主机执行，也未验证原生完整证明能力的一致性。

## 故障与遥测边界

EvaluationAuthorizationError 独立于普通 LLM／供应商故障。到期、撤销、路由拒绝、预算／速率耗尽，以及网关权限不可用时，系统会停止执行，而不是尝试所有供应商。自适应恢复会记录失败尝试／终态证据，不会进行切换。真实上游的读取／连接／协议故障仍遵循现有有界策略决策；网关回退不会取代 Main-Agent 运行时。同一 Run/Task 身份和原始候选优先级保持不变。readiness 表示配置的授权状态，绝不是新增能力认证。

仅返回系统定义的错误类别；请求校验不会回显提交字段。网关审计排除 bearer 值、上游凭据、Authorization 请求头、提示词及隐藏推理。已知 Owner 密钥／令牌会从发出的响应体中过滤；这是纵深防御，不能保证阻止被攻陷的上游故意编码秘密。网关绝不会有意在模型提示词或数据载荷中包含供应商密钥。TLS 密钥、部署日志、代理／APM 设置和崩溃转储仍由 Owner 负责。

## 明确限制

这是一个有界的评估网关，不是企业 Auth/RBAC/SSO、商业计费、按金额成本强制限制、分布式配额服务，也不能保护已被攻陷的 Owner 服务器。按请求数计量的配额可能被重试或失败／状态不确定的操作消耗。撤销之后，已获授权且正在执行的请求仍可能完成。固定分钟限额需要边缘层控制来应对突发／未认证流量。数据库备份与权限必须保持私密和一致；回滚计数器并不安全。

测试确立的是离线契约行为，不是真实部署，也不是秘密绝不会泄露的保证。本任务未进行真实供应商调用、生产研究 Run 或实际网关部署。请参阅 [Owner 部署要求](../deployment/EVALUATOR_GATEWAY.zh-CN.md)。
