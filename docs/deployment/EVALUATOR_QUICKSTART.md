# Evaluate Verifiable Financial Agent

Start with [Guided Installation](INSTALL_EVALUATOR.md): one platform command prepares local services and database, imports your Owner-issued encrypted credential, checks authorization and opens the product.

After installation, open a new terminal and run `vfa start`. Use `vfa stop`, `vfa status`, `vfa doctor`, `vfa update` and `vfa open` for everyday operation.

Public installer URL: **PUBLICATION_REQUIRED**. Real Owner gateway: **NOT_DEPLOYED**. Until those operational prerequisites exist, use the privately supplied source package for installer validation; do not assume Owner-funded research is available.

Standard container delivery retains every proof/release gate and has limited workflows. Full required-proof/generated-capability execution uses [Advanced Installation](ADVANCED_INSTALLATION.md). Provider keys are not needed on evaluator machines. BYOK remains available for independent deployment.
