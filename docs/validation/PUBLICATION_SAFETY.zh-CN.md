## 秘密检查

- 扫描了 4,082 个文本 Git 对象，查找供应商密钥模式、JWT、私钥标记、凭据赋值以及包含凭据的数据库 URL。
- 经审查，匹配项为占位符、代码表达式和明确的安全测试 fixture；未发现实际秘密。
- 补充的内联凭据／查询赋值扫描经分类后，只发现一个领域类型注解，而非字面量凭据。
- 将四个已配置的私有供应商／可观测性凭据值，与全部可达 Git blob（包括二进制内容）进行了精确匹配检查；零匹配。这些值从未被打印、复制或保存进审计产物。
- 当前受跟踪 dotenv 文件仅有 .env.example。真实 .env.local／私有权限文件仍被忽略且未跟踪。
- 未引入新的私有运行时载荷、提示词／响应转储、生产数据库、原始 Alpha 参与者记录或原始截图杂项。
- 现有受跟踪的视觉比较材料仍为历史证据，不是实时评估者种子数据。新增投资者截图仅为五张已获准的最终产品画面。

## 可移植性／隐私

移除了运行时 MiMo 的开发者主目录默认值。评估者使用自己的 Settings 或显式私有权限文件。历史辅助脚本现在使用正常仓库配置，而不是固定 Owner 主目录。归档工程命令使用可移植的仓库占位符。安全测试中的通用假私有路径字符串是刻意设计的测试输入。

公开示例只应包含模型 ID、公开配置基础 URL 和变量名。访问凭据仍采用 BYOK 或由 Owner 通过带外方式签发。未来新增本地产物和参与者观察记录前，必须单独审查。

## CI 准备

最小工作流：.github/workflows/local-contracts.yml。不需要外部秘密、PostgreSQL 服务、真实 FMP、真实供应商或证明执行。安装需要普通软件包仓库访问。工作流内容已用 Python 3.11 和 Node 24.20.0 在本地执行；尚未在 GitHub 托管环境执行（未推送）。CI_STATUS 指的是本地准备验证，而非远端绿色检查。
