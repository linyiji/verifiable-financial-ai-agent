limitations and typed blocking reasons. Frozen qualitative contracts remain

explicit downstream optional/fulfilled ANY_OF contracts, scoped to real graph

An approved child with no optional contract remains required; task names never
grant generic follow-up exemption. Unknown integrity exceptions remain fatal.

Required gaps stop before Review/Proof. Reviewable partial packages use the
ordinary Review, Proof policy, Release gate and report path. Typed reasons cross
the public projection boundary; scheduler failures are no longer mislabeled as
assurance exceptions. No failed historical task, Run or proof is rewritten.

or Proof. Local acceptance uses synthetic offline fixtures, including actual
