# 自适应恢复验收

[English](ADAPTIVE_RECOVERY_ACCEPTANCE.md)

已验收的历史当前 Run 达到 RELEASED，期间观测到同一 Run 内的 Peer 调用恢复：MiMo 传输超时、明确的 ALLOW 策略决策，以及 Sol 回退成功。Input/Task/Run 谱系始终绑定；必需的财务审查／证明与常规发布门均未被绕过。

界面展示恢复尝试、决策、路由和结果证据。这与语义纠错／重新规划不同；仅有供应商故障并不授权新的研究意图。

离线契约测试覆盖策略上限、身份／能力约束、不安全情形的拒绝，以及自适应执行。仓库准备工作未使用真实供应商或数据调用。

范围仅限有界恢复基础，不包括完整 Evaluation/POT、无限制的自主路由优化，也不保证所有新的供应商故障都能恢复。
