# 模型传输可观测性

[English](MODEL_TRANSPORT_OBSERVABILITY.md)

共享的 OpenAI 兼容 HTTP 边界为 TeamoRouter 和 MiMo Direct 记录有界传输元数据。
通过既有 `VFA_PERFORMANCE_PATH` 显式启用性能记录即可启用；既有记录器 snapshot/flush 路径
保留增强后的 `model.http` span。不新增独立日志接收端。

## 证据语义

- 会话 ID、逻辑调用 ID、父尝试 ID、进程 ID、稳定客户端 ID、供应商 / 模型 / 路由、任务配置、依赖版本和单调 span 时长用于关联观测到的尝试。路由不可用时为 `UNKNOWN`。
- 自有客户端的创建时间在构建后立即观测；调用方拥有的客户端创建时间为 `UNKNOWN`。完成时记录实际关闭状态，但不关闭调用方拥有的客户端。
- 生效代理元数据来自所选 HTTPX transport mount，而非再次读取环境。只保留主机及端口。不支持 / 自定义 transport 检查时为 `UNKNOWN`。私有 HTTPX 检查是尽力而为，并针对已安装 HTTPX 栈进行测试。
- TCP 建连目标可能是代理，不是供应商源站。仅 TLS 完成不能证明供应商健康。复用连接可能使当前请求的 TCP 建连状态保持 `UNKNOWN`。
- 跟踪事件区分请求发送、响应头、正文读取及完整响应。未观测阶段保留 `UNKNOWN`，不推断成成功或失败。代理 CONNECT 响应头不是供应商响应头。
- `concurrent_http_attempts` 统计此进程 / 事件循环中已插桩的进行中 HTTP 尝试，包含当前尝试；它不是所有任务、逻辑调用或跨 worker 调用总数。
- 异常类及异常链只使用已知库类身份。未知子类保持 `UNKNOWN`。此插桩绝不保留原始异常字符串、凭据、头、提示词或响应正文。

路由、trust_env、超时 / 重试 / 回退设置、HTTP 版本、客户端归属、连接池及研究 / 产品契约均未改变。
